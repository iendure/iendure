ENDURE is a house of focused, durable tools for developers, writers and
anyone who works with text, terminals and structured knowledge.

Each brand solves one problem well. No bloat, no tracking, no dark
patterns. Just tools that outlast trends.

## Brands

| Brand | What it does | Status |
|---|---|---|
| [**2Clipboard**](https://github.com/iendure/2Clipboard) | Universal clipboard utility for Linux. Generate, format and copy project codes, file attachments, command output and booleans. | ✅ v2.2.0 |

More coming. Follow the organisation to know when.

## Philosophy

- **One tool, one job.** No feature creep.
- **Terminal-first.** Everything usable from the CLI, scriptable, testable.
- **No telemetry.** Your data stays on your machine.
- **Open source.** MIT, always.
